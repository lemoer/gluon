Der Knotenname dient ausschließlich zur Identifikation deines Knotens, z.B. auf einer Knotenkarte. Er hat keinen Einfluss auf den Namen (SSID) des ausgestrahlten WLANs.
Hier musst du deine Standortzugehörigkeit festlegen. Wähle deine Stadt und gegebenenfalls den Stadtteil aus. Passt keine andere Option, wähle die Domäne "Umland" aus. Die Standortzugehörigkeit legt fest, mit welchen Freifunk Knoten sich dein Knoten verbinden kann (Mesh-Netz).
Dein Knoten kann deine Internetverbindung nutzen, um darüber eine VPN-Verbindung zu anderen Knoten aufzubauen. Die dafür genutzte Bandbreite kannst du beschränken. Aktiviere die Option, falls keine per WLAN erreichbaren Nachbarknoten in deiner Nähe sind oder du deine Internetverbindung für das Mesh-Netzwerk zur Verfügung stellen möchtest.
Um deinen Knoten auf öffentlichen Karten anzeigen zu können, benötigen wir seine Koordinaten. Hier hast du die Möglichkeit, diese zu hinterlegen. Wenn dein Computer aktuell mit dem Internet verbunden ist, kann die Position auch auf der hier angezeigten Karte ausgewählt werden.
